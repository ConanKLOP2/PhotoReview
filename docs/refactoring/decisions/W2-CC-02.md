# W2-CC-02 - hidden/System folders in sibling navigation

## Current state

PageUp/PageDown moves to the previous/next sibling folder. Sibling enumeration does not filter by attributes, so a Hidden/System
folder that contains images (for example a `.thumbnails` folder) can be navigated into and its images are reviewed like any others.
Unverified: whether the main folder load (opening a folder) includes Hidden files; the code PR reports it.

## Options

| | Change | Pros | Cons |
|---|---|---|---|
| A | Leave | No change, no risk | Navigation lands in tool/cache folders the user never meant to review |
| B | Always skip Hidden/System sibling folders | Small, no UI, no new key; matches what Explorer shows by default | A user who keeps photos in a hidden folder cannot reach it by PageUp/PageDown (opening it directly still works) |
| C | Setting "include hidden folders" (default off) | Covers both groups of users | Adds a setting, config key, Settings UI and localization for a rare case; more to test |

## Decision

Option B, chosen by the user on 2026-10-06. The current folder is always kept in the sibling list even if it is hidden, so
navigation from it still works. Code: separate PR on branch `fix/sibling-nav-skip-hidden`.

## When to revisit

If a user reports that photos in a hidden folder cannot be reached by sibling navigation: then option C.
