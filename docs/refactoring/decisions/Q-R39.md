# Q-R39 — zoom cluster togglable in the context menu

New `AppSettings.ShowZoomMenuItems` (`src/PhotoReview.Core/Settings/AppSettings.cs`) hides the right-click
context menu's zoom cluster -- `FitMenuItem` ("Fit to window"), `ZoomToLevelMenuItem` ("Zoom to N%") and
`ZoomMenu` (the "Zoom" submenu) -- as one unit, same pattern as Q-R38's `ShowFolderMenuItems` for the folder
group. **Default false (hidden)** -- unlike `ShowFolderMenuItems` (default true/visible), this is new behaviour
the user explicitly wants off by default.

The separator directly above the cluster, right below Undo, was previously unnamed; it is now
`ZoomGroupSeparator` in `MainWindow.xaml` so it toggles with the cluster. This avoids a dangling double
separator when both the zoom cluster and the folder group are hidden at once (menu reads `Undo` / `Settings`
with no stray separators in between).

`MainWindow.xaml.cs` `ImageContextMenu_Opened` sets `ZoomGroupSeparator`/`FitMenuItem`/`ZoomToLevelMenuItem`/
`ZoomMenu` visibility from `_settings.ShowZoomMenuItems` on every open, mirroring the `folderGroupVisibility`
block. The zoom items' own shortcuts keep working when the menu items are hidden, same as the folder group's
Next/Previous folder shortcuts.

Settings > Right-click menu gained a second checkbox (`ShowZoomMenuItemsCheck`) next to the existing
`ShowFolderMenuItemsCheck`, wired the same way (load/Defaults-reset/Save). New localization keys
`settings.showZoomMenuItems.label`/`.automationName`/`.hint` (en/vi).
